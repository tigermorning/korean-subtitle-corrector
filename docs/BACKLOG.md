2026-08-02에 그 축적 작업 자체를 안 하기로 결정했다. **판례 스터디는 다시
꺼내지 않는다 — 영구 종결.** 그 결과 1번도, 뭘 "연동"할지 애매했던
**7번(온라인가나다 연동 2단계, 코드 0건)**도 같이 닫는다.

이미 쌓인 `docs/GRAMMAR_PRECEDENTS_TABLE.md`·`gananda_precedents.py`·

않는다 — 실제 애매 사례를 만났을 때 그 자리에서 낱건으로 확인해 표에 추가하는
것까지 막는 결정은 아니다.

### 34. `_specialist_reading_supported()`의 분야 신호가 목표 낱말의 무관한 뜻까지 끌고 온다 (2026-09-02 접수, §90)

`engine/replacements.py`의 "옛 용어" 오탐지 억제 로직(§73이 만든 것) 중
①분야 계열 신호가 `sense_fields(target)`으로 목표 낱말의 분야를 구하는데,
**어느 구체적 뜻이 "옛 용어" 관계와 관련 있는지 안 가리고 그 낱말의 모든 뜻을
다 본다.** 실측: '정수'(精髓, 흔한 뜻)가 '양수'의 옛 용어로 오탐지됐는데,
'양수'의 12개 뜻 중 '정수'와 무관한 '양수(讓受, 권리를 넘겨받음 — 법률
용어)' 뜻 때문에 `sense_fields('양수')`에 '법률'이 섞여 들어갔다. 게다가
`_field_group('법률')`이 {정치·경제·행정·법률}로 넓게 묶여 있어서, 구청장·
예산·개최·협약 같은 낱말이 흔한 행정 보도자료류 문서는 거의 다 이 신호에
걸린다.

**스톱리스트로는 못 막는다** — §73 사고(생 문장 몇 개의 흔한 낱말 겹침)와
달리 이건 분야 카테고리 자체가 새는 것이라 목록이 끝없이 늘어난다. 제대로
고치려면 `sense_fields()`를 "옛 용어" 관계와 실제로 연결된 그 뜻으로 좁혀야
한다. **착수 전 확인**: 이 함수를 고치면 §73(건초→힘줄집)·§80이 기대는 다른
경로도 건드릴 수 있으므로, 원래 동기가 된 사례들과 새 사례를 모두 통과하는
회귀표를 먼저 만들 것(`grammar-rule-verify-then-code`에 준함).

당장 도움 되는 실사용 발견: 실측으로 확인한 사이드 이펙트 하나 —
`_CONTEXT_STOP_LEMMAS`(②정의 낱말 겹침 신호가 쓰는 불용어 목록)에 '들다'·
'올리다'·'건강' 셋을 추가해 §73과 같은 부류의 흔한 낱말 오염은 이미
막았다(코드 반영 완료). 이 항목은 ①분야 신호 쪽만 남았다.

### 5. 지역어 종합 정보 API 500 장애 — 외부 요인, 대기

**2026-09-02 재확인: 여전히 500이다** — 07-27 최초 발견 이후 매번 같은 증상.
같은 4개 질의(`정구지`·`머스마`·`무싯날`·`감자`)로 실제 클라이언트 파라미터

아니었다 — 헤더를 붙여도 500이다.

`search_dialect()`가 실패를 삼키고 `[]`를 돌려주므로 "장애"와 "매칭 없음"이
구분 안 된다 — **상태 확인은 반드시 원 요청으로 할 것**(clients.py의
`DIALECT_URL`에 같은 파라미터로 직접 GET). 서버가 복구되기 전에는 우리 쪽에
할 일이 없다. 사투리 assist의 표준어→사투리 역방향이 막혀 있는 근본 원인(§12).

### 31. 외래어 표기법 언어별 세칙 전면 도입 — 착수 대기 (2026-08-14 사용자 지시)

국립국어원 「외래어 표기법」은 기본 원칙 5개 조항 아래 **언어별 표기 세칙**이
방대하다. 지금은 용례 조회(표준국어대사전·우리말샘·kornorms)에만 기대고 있어
세칙 자체를 규칙으로 갖고 있지 않다.

**우선순위(사용자 지정): 영어 · 독일어 · 프랑스어 · 중국어 · 일본어.** 장기적
으로는 전 언어 반영. 착수 지점(작업자 자료에서 이미 옮겨 적음):

- **기본 원칙 제3항(받침은 `ㄱㄴㄹㅁㅂㅅㅇ`만)·제4항(파열음에 된소리 금지)은
  "기계가 잰다"고 여기 적혀 있었는데 틀렸다(2026-09-02 검증, §88) — 아래
  "발음 없이도 못 하는 이유" 참고.** 제4항은 태국어 세칙(`t→ㄸ`,`k→ㄲ`,`p→ㅃ`)
  예외도 있어 언어를 모르면 오탐지한다.
- 영어: 무성 파열음 [p t k]는 단모음 뒤에서만 받침, 그 외엔 `으` / 유성
  파열음 [b d g]는 언제나 `으` / **[ʃ]에 `쉬`를 쓰지 않는다** / 약어 `R`=아르,
  `&`=앤드.
  일본어: 어두/어중·어말에 따라 청음·유성 갈림(카키쿠케코 ↔ 가기구게고),
  `zu`·`su`→`즈`·`스`. 중국어: 한어 병음 대조표, `z→ㅉ`, `c→ㅊ`, `s→ㅆ`.
- 언어마다 무엇을 대조하는지가 다르다(영·독·프는 발음기호, 스페인·이탈리아·
  러시아는 철자, 중국어는 한어 병음). 예외 규정(관용이 이기는 자리, 등록상표,
  뜻이 갈리는 복수 표기 등)은 `docs/LOANWORD_EXCEPTIONS.md`에 모아 뒀다.

**"먼저 할 일" 해결됨(2026-09-01).** `exampleReqList.do`는 확인대로 용례만
준다. 세칙 원문은 `regltnView.do?regltn_code=0003` 열람 페이지에 실제로 다
있다 — 단 이 페이지는 자바스크립트로 본문을 그려서 **정적 fetch(WebFetch)로는
제3장(표기 세칙) 이후가 잘려 나온다.** Browser 도구(JS 렌더링)로 열어야
전문이 보인다는 것까지 실측으로 확인했다. 우선순위 5개 언어(영어·독일어·
프랑스어·중국어·일본어) 세칙 조문을 전부 이 방법으로 가져와
`docs/LOANWORD_TRANSCRIPTION_RULES.md`에 옮겨 뒀다.

**다섯 언어의 난이도가 균일하지 않다는 것도 확인했다.** 일본어·중국어 세칙은
가나·한어병음이라는 **문자 체계** 기준이라 표 4·표 5 대조표만 있으면 되는데,
**영어·독일어·프랑스어 세칙은 전부 국제음성기호(IPA) 전사 기준**(`cat[kæt]`
처럼)이라 엔진이 보는 한글 표기만으로는 판정 근거(원어·발음기호)가 없다 —
(1)한글→원어 역산 (2)원어→발음기호 변환(영어는 CMU 발음사전류, 독일어·
프랑스어는 별도 소스 필요, 지금 저장소에 없음) (3)발음기호→세칙 적용의
인프라가 선행돼야 한다. **어느 발음사전을 쓸지부터 사용자와 정해야 착수할 수
있다 — 아직 안 함.**

**"발음사전 없이 되는 부분"도 확인했지만 막힌다(2026-09-02, §88, 사용자 지시로
재검토).** 제3항(받침)·제4항(된소리)은 IPA 역산이 필요 없어 언뜻 기계적으로
보이지만, 걸리는 것은 발음이 아니라 **"이 낱말이 애초에 외래어인가"를 텍스트
만으로 알 방법이 없다는 것**이다. 금지 받침(ㄷㅈㅊㅋㅌㅍㅎ 등)·된소리
(ㄲㄸㅃㅆㅉ)는 고유어에도 흔하다("부엌"·"밭"·"꽃"·"깜짝"·"딸") — 사전 미등재
(`is_standard_word()`=False)라는 것만으로 외래어 후보로 보면, 사전에 없는
고유어 이름(예: "빛나")까지 외래어 받침 위반으로 오탐지한다. ㅈ·ㅉ·ㅊ+반모음
규칙(§82)이 예외적으로 안전했던 건 그 음절 조합 자체가 고유어에는 애초에
안 나오기 때문이었다(한글의 ㅈ·ㅉ·ㅊ은 이미 구개음이라 반모음을 더 적어도
소리가 안 바뀜) — 받침·된소리는 그런 우연이 없다. **결론: 발음사전이 아니라
"외래어 판별기"가 없는 것이 진짜 장벽이고, 지금 이 저장소엔 그것도 없다.**
안전하게 쓰려면 번역가가 원어를 직접 확인해 주는 자리(§61 원어 입력칸)처럼
**이미 외래어라고 확정된 낱말**에만 적용해야 한다 — 자막 전체를 훑는 자동
규칙으로는 착수 불가로 재확인.

**중국어 세칙 제2항(ㅈ·ㅉ·ㅊ 뒤 ㅑㅖㅛㅠ 금지, 쟈→자 등)은 구현 완료
(2026-09-01, §82).** 유일하게 원어 정보 없이 한글 표기만으로 기계적 판정이
가능했던 조항이다. `check_palatal_glide_loanword()`(`engine/loanwords.py`),
확인 플래그 전용, kornorms 미등재 신조어만 대상(등재된 건 `correct_loanwords()`가
먼저 처리). kornorms 실측으로 이 12음절이 중국어 전용이 아니라 영어·독일어·
프랑스어·에스파냐어·일본어에도 걸쳐 있는 일반 표기 관행임을 확인했다 — 상세는
§82. **일본어 촉음·장모음, 중국어 성조 규칙은 영·독·프와 같은 벽**(원어 가나/
병음 정보가 없어 한글 표기만으로 위반 여부를 판정할 수 없음)이라 미착수.

상세 조문·기술 격차 설명은 `docs/LOANWORD_TRANSCRIPTION_RULES.md` 참고.

   거꾸로 적힌 라벨 오류였다 — 정정. w23·w27은 kornorms·사전 어디에도 없어
   조회불가로 표시(w23은 31번 선행 필요). w29(커리/카레)는 kornorms가 '커리'를
   인명 'Cori'의 오표기로만 등재해 둬서(33번과 같은 동형이의어) 텍스트만으로
   못 고치는 받아들인 한계로 남김. **나머지 21건은 전부 엔진이 아직 구현하지
   않은 개별 규칙**(명사+명사+하다 재분리, 부사·보조용언·단위 띄어쓰기,
   완전/완전히, 아니오/아니요, -구먼/-구만, 외래어 받침, 형용사형 국명, 인명·
   상표 관용 표기)이다 — 라벨은 대부분 검증됐으니(`verify_eval_labels.py`)
   새로 만들려면 항목별로 `grammar-rule-verify-then-code`를 거칠 것.
4. **이미지 62장의 규범 표 — 문장부호(§83)·001~012·042~050·054~064 그룹 검토
   완료(2026-09-02, §83·85·86·87), 새 규칙 2건(자동 교정 1·확인 플래그 1).
   남은 022~041(외래어 세칙)은 31번 범위라 여기서 새로 만들지 않는다 —
   31번을 다시 꺼내기 전까지 이 항목은 사실상 종결.**
   원본 `.docx`에서 문단 순서대로 이미지를 추출하는 방법은
   `이미지-판정.md`의 "방법 기록" 그대로(같은 순서 = NOTA 번호) — 세션 스크래치패드
   추출본은 매번 사라지므로, 다시 뽑으려면 `docs/log-archive/2026-h2.md`나 §85가
   아니라 이 방법을 그대로 다시 돌릴 것.

   **NOTA-013~021(문장부호) — 재확인 결과 전부 처리됨(§83이 맞았다, 오해 정정).**
   013(범위 표기)·015(쉼표)·017(물결표/붙임표)은 옆 저장소(`subtitle-tc-generator`)
   가 이미 함, 014(날짜 온점·로캘별 소수점 표기)는 번역 판단이라 스코프 밖,
   016(말줄임표)·018(따옴표)·021(전각반각)은 `options.py`가 커버, 019(쌍점)·
   020(`&`)·NOTA-053(단위 대소문자)은 §83이 구현. **문장부호 그룹은 완결.**

   **NOTA-001~012 — 재검토, 5개 구현.**
   - 001~003(띄어쓰기 판별 단계, 품사 기준) — 개념 설명 자체가 이 엔진의
     kiwi POS 기반 판정 원리와 같다. 새 코드 없음.
   - **004(의존명사 문장 첫머리 금지) — 구현.** `나름`·`때문`이 앞말 없이
     줄 첫머리에 오면 확인 플래그(`dependent_nouns.check_dependent_noun_sentence_start`).
     자동 교정은 안 함 — 자막은 문장이 여러 줄로 쪼개져 앞 줄의 꾸밈말을
     이어받는 경우가 흔해서다. 실제 자막 4개 파일 1,926줄로 오탐률 확인:
     1건뿐이고 그나마 다른 낱말('척')의 오태깅이었다.
   - 005(변경된 용어: 터키→튀르키예, 나트륨→소듐 등) — **자동화 금지 대상으로
     확정.** 이미지 자체가 '논란'·'회귀'(되돌아간 표기도 있음) 라벨을 달아 둠 —
     정치·과학용어 표기 다툼은 사람 판단.
   - 006(순화어 주의) — **자동화 금지 대상으로 확정.** 이미지 제목이 "주의"이고
     실제로 안 쓰이는 억지 순화어(곤돌라→방승기 등)를 스스로 예로 듦.
   - **007(제-차 표기) — 구현.** 접두사 '제'를 뒤 말에 붙인다
     (`affix.correct_ordinal_prefix_je`). kiwi가 순번의 '제'(XPN)와 대명사
     '제'/저의(NP)를 정확히 갈라 태깅해 자동 교정. '차'는 붙여도 띄워도
     맞으므로 안 건드림.
   - 008~009(숫자 한글/아라비아 표기 원칙, 사전 신뢰도 안내) — "나음"(권장)
     이지 오류가 아니고, 사전 종류 안내는 규칙이 아니라 참고 정보. 새 코드 없음.
   - 010(합성어 예시 목록) — 이미 `word_exists` 그대로. 새 코드 없음.
   - 011~012(구어체 나이 표기·번역투 'N의 명사') — **자막 문법**(구어체 대사 vs
     문어체 화면자막 스타일)이라 이 저장소가 아니라 옆 편집기 몫. 012는 설사
     이 저장소 몫이었어도 등록 여부 판단이 아니라 자연스러움 판단이라
     원리 2(모호할 때 자동 교정 금지) 대상.

   **번호-내용 매핑 주의(2026-09-02 발견)**: `.docx`의 캡션 텍스트박스가 인접
   이미지로 밀려 붙는 문서 구조 때문에, 추출 스크립트가 매긴 NOTA-N 번호가
   `이미지-판정.md`가 말하는 실제 내용과 어긋나는 경우가 있다(예: "종결어미
   -요/이요"라고 캡션이 달린 자리의 실제 이미지는 '부딪치다/부딪히다'였다).
   아래 "맞춤법 그룹" 항목은 그래서 정확한 NOTA-N 대신 **내용으로** 적는다 —
   번호는 재확인 전까지 참고만 할 것.

   **맞춤법 그룹(054~062 부근, 9장) — 재검토, 새 자동화 대상 0건.**
   - 명사구 붙임/띄움 목록(오늘 밤·지난주·이틀간 등) — 이미 `word_exists` 기반
     합성어 판정 그대로. 새 코드 없음.
   - 부딪치다/부딪히다(능동/피동, 문맥에 따라 갈림), 종결어미 -대/-데(전달/경험,
     뜻이 다름), 한번/한 번(강조·시도 vs 수효, 뜻이 다름), 잘못되다/잘 못되다/
     잘 안되다(뜻이 다름) — **전부 원리 2(모호할 때 자동 교정 금지) 대상.**
     맞춤법 오류가 아니라 뜻이 다른 낱말·표현을 고르는 문제라 자동 판단 불가.
   - **-ㄹ걸(어미)/걸(의존명사, =것을) — 검토했으나 자동화 불가로 확정.**
     "모를걸?"(안 띄움)은 kiwi가 어미(EF) 한 토큰으로, "모를 걸?"(띄움)은
     의존명사+조사(NNB+JKO) 두 토큰으로 읽는다 — 서로 다른 태그처럼 보이지만
     **원문의 띄어쓰기를 그대로 따라가는 순환 신호**임을 실측으로 확인했다
     (같은 문장을 띄우거나 붙여 넣으면 kiwi 판독이 그때그때 따라 바뀐다).
     이 신호로 사용자의 원래 의도를 가를 수 없다.
   - 뿐(조사/의존명사) — 이미 `correct_bun_spacing`이 처리. -ㄹ뿐더러(어미)는
     드문 자리라 보류.
   - 맨(관형사)/맨-(접사) — 이미지가 틀린 예시 없이 올바른 용례만 보여 준다.
     고칠 오류가 없어 보류.
   - 보조 용언 띄어쓰기 분류표 — 기존 `_aux_verb_spacing`(제47항) 체계와
     같은 내용의 참고표. 새 코드 없음.

   **고유명사 띄어쓰기 그룹(042~050 부근, 9장) — 검토 완료, 새 자동화 대상
   0건.** 지명 접미어 붙임(발트해·나일강·쓰촨성 등)과 동식물 품종명 붙임
   (아프리카코끼리 등)은 실측으로 확인해 보니 **이미 기존 합성어 병합
   플래그(`check_compound_merge_candidate`)가 그대로 잡는다** — 둘 다 사전
   표제어라 별도 규칙이 필요 없었다(`아프리카 코끼리를 봤다` → 이미
   "'아프리카코끼리'가 사전 표제어이므로 붙여 쓸 수 있습니다" 플래그 확인).
   나머지(Mac/Mc 이름, van/von/de 같은 유럽어 소문자 전치사, 상표명·인명
   음차, 복수 표기 다의어)는 전부 **외래어 표기법 세칙**이라 31번 범위다 —
   여기서 새로 만들지 않는다(중복·충돌 방지). 063~064(2장)는 사진 한 장과
   번역 자연스러움 조언이라 대상 아님.

   **62장 중 새 자동화 대상을 찾는 이 방식의 수확은 사실상 끝났다(2026-09-02).**
   남은 것은 전부 ① 외래어 세칙(022~041, 31번 범위 — 발음사전 도입 여부를

   (005·006·011·012, 정치/과학 용어 논란·억지 순화어·자막 문법)뿐이다.
   **31번을 다시 꺼내기 전까지는 이 항목에서 더 볼 것이 없다.**
