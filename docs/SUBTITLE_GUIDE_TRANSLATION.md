## 1. 넷플릭스 — 공통 기술 요건 (General Requirements, 최신 2022-10-07)

번역 자막·SDH **양쪽에 공통 적용**된다. (SDH 문서와 동일 내용)

- **표시 시간**: 최소 5/6초(24fps 기준 20프레임), 최대 7초
- **줄 수**: 최대 2줄, 글자 수 제한 내에서는 1줄 선호
- **위치**: 상단 또는 하단, 가운데 정렬 (일본어만 세로쓰기 허용). 화면 텍스트와 겹치면 위치 조정, 불가하면 가독성 우선
- **파일 포맷**: TTML1 (.xml/.ttml). 일본어는 IMSC 1.1
- **TTML 규격**: % 값만(px 금지), `tts:textAlign`/`tts:displayAlign`(정적 값), `tts:fontSize` 100%
- **문자**: Netflix Glyph List 내 문자만
- **줄바꿈 원칙**: 문장부호 뒤 / 접속사·전치사 앞에서 끊기. 관사+명사, 형용사+명사, 이름+성, 주어 대명사+동사, 전치사구, 조동사·재귀대명사·부정어+동사 분리 금지. **역피라미드(아래 줄이 더 긴) 형태** 선호
- 시즌/에피소드 간 KNP(고유명사)·존댓말 테이블로 일관성 유지
- **통화 환산 금지**
- 브랜드명: 현지 통용명 → 현지 대응명 → 일반명사 순
- 그 외 이 문서에서 다루는 항목: Netflix 크레딧 번역, 메인 타이틀/헌정 문구, 인용, 번역가 크레딧

## 2. 넷플릭스 한국어 번역 자막 (Korean TTSG **Section I**, 최신 2025-07-07)

원문 목차: I.1 Acronyms / I.2 Character Limitation / I.3 Character Names / I.4 Continuity / I.5 Documentary·Unscripted / I.6 Dual Speakers / I.7 Font Information / I.8 On-screen Text / I.9 Foreign Dialogue / I.10 Italics / I.11 Line Treatment / I.12 Numbers / I.13 Punctuation / I.14 Quotes / I.15 Reading Speed Limits / I.16 Repetitions / I.17 Songs / I.18 Titles / I.19 Treatment / I.20 Special Instructions / I.21 Reference

### 2.1 수치 (I.2 / I.11 / I.15)

| 항목 | 값 |
|---|---|
| 한 줄 글자 수 | **16자** (라틴 문자·공백·문장부호는 0.5자로 계산) |
| 읽기 속도 — 성인 | **초당 12자** |
| 읽기 속도 — 아동 | **초당 9자** |
| 줄 수 | 최대 2줄, 기본 1줄 |
| 2줄 예외 | 한 줄에 문장부호 3개 이상 포함 / 인용문 |

> SDH(14 / 11 CPS)보다 **느리다.** 같은 대사라도 번역 자막이 더 압축돼야 한다.

### 2.2 이탤릭 (I.10)

- **이탤릭 사용 금지.** (영어 가이드와 정반대이므로 주의)

### 2.3 문장부호 (I.13)

- **줄 끝에 마침표·쉼표를 절대 쓰지 않는다**
- 한 자막 안에서 문장을 구분하는 쉼표는 사용 가능
- 느낌표는 고함·놀람에만, 남용 금지. `?!`(인테러뱅) 허용
- 해시태그 기호 사용 가능(동사로 쓸 때는 "해시태그"로 풀어쓰기)
- 약어 내 `&` 허용 (R&B, B&B)

### 2.4 연속성·말줄임표 (I.4)

- 점 3개(`...`)가 아닌 **U+2026(`…`) 단일 문자**
- 문장이 연속 자막으로 이어질 때는 말줄임표·대시 **생략**
- 2초 이상 정적, 머뭇거림, 말이 끊길 때 말줄임표 사용
- 정적 뒤 문장이 계속되는 경우, 두 번째 자막 앞에는 말줄임표를 붙이지 않음
- 문장 중간에서 시작하는 자막임을 나타낼 때만 **공백 없이** 앞에 말줄임표

### 2.5 따옴표 (I.14)

- **큰따옴표 `" "`**: 화면 삽입 텍스트(촬영 시 삽입된 텍스트, 화면 자막, 메인 타이틀)
- **작은따옴표 `' '`**: 인용된 말, 인용문, 강조, 작품 제목, 소리 내어 읽기, 손가락 따옴표
- 따옴표를 쓰지 않는 경우: 다른 시공간의 보이스오버, 회상 속 목소리, 상황 설명
- 인용이 여러 자막에 걸치면 시작·끝에 따옴표

### 2.6 화면 텍스트 / 강제 자막 (I.8)

- 플롯상 중요할 때만 표기
- 대사와 겹치면 더 중요한 쪽 우선
- 화면 표시 시간과 최대한 일치, 중복되면 삭제
- **대사와 같은 자막에 절대 합치지 않음**
- 강제 자막이 대사를 끊고 들어올 때 앞뒤 자막에 말줄임표를 넣지 않음

### 2.7 2인 화자 (I.6)

- **하이픈 + 공백**, 한 줄에 한 명
- 각 줄은 완결된 문장, 앞뒤 자막으로 문장을 넘기지 않음

> 영어 가이드는 **공백 없는 하이픈**이다. 한국어와 다르다.

### 2.8 인명 (I.3)

- 넷플릭스 승인 번역이 없으면 고유명사 번역 금지
- 한국어 음역 지침(외래어 표기법)에 따라 음역
- 별명은 특정 의미를 전달할 때만 번역
- 역사적 인물은 약칭으로만 알려진 경우를 빼고 약칭 지양
- 역사·신화 인물은 언어별 정착 번역 사용
- 미들네임에 마침표가 쓰인 경우 원본 형식을 따름

### 2.9 외국어 대사 (I.9)

- 원본에서 자막이 제공된 경우(=시청자가 이해해야 하는 경우)에만 번역
- 번역 가능한 단어·구는 번역, 없으면 음역
- 외국어 대사 구분에 작은따옴표 사용 가능

### 2.10 숫자 (I.12)

- 공간·읽기 속도를 고려해 숫자/한글 표기를 판단
- **24시간제는 군대 맥락 외 사용 금지**
- **원화로 환산 금지**
- 도량형은 플롯상 중요하지 않으면 미터법으로 변환

### 2.11 약어 (I.1)

- 영어 약어는 글자 사이 마침표 없이 표기 (CD, DVD, DNA)

### 2.12 반복 (I.16)

- 같은 화자가 한 자막에서 반복하는 말은 한 번만 번역
- 연속 2회 반복은 오디오에 맞춰 싱크하되 번역은 한 번만

### 2.13 노래 (I.17)

- 판권이 있고 플롯상 중요할 때만 자막화
- 오프닝·엔딩곡은 명확히 플롯상 중요하거나 별도 지시가 있을 때만
- **이탤릭 없음, 따옴표 없음**
- 줄 끝에는 물음표·느낌표만 (마침표·쉼표 금지), 줄 안 쉼표는 필요 시 허용
- 배경으로 계속되지만 자막을 멈출 때 말줄임표

### 2.14 제목 (I.18)

- 메인 타이틀은 KNP/Terminology의 승인 제목만 사용, 새로 번역 금지
- 화면 제목과 승인 제목이 동일하면 자막 미표기
- 승인 제목이 화면과 일부만 일치하면 자막 표기
- 승인 제목은 글자 수를 넘겨도 여러 자막으로 쪼개지 않음
- 메인 타이틀에 이탤릭 없음
- 에피소드 제목은 화면에 나오거나 음성으로 언급될 때만 자막화
- 기존 출판물·영화·TV는 공식 또는 널리 알려진 번역 사용, 없으면 번역·음역

### 2.15 다큐멘터리·비대본물 (I.5)

- 화자의 직함은 **첫 등장 시 한 번만** 번역
- TV·영화 클립 속 대사는 플롯상 중요하고 판권이 있을 때만 자막
- 뉴스 티커·배너는 플롯상 중요할 때만 자막

### 2.16 존댓말·반말 (I.19 Treatment)

- 맥락, 인물 관계, 시대 배경으로 결정
- **성별이나 나이만으로 결정하지 말 것**
- 관계의 역학에 맞춰 어투 결정

### 2.17 특별 지시 (I.20)

- **검열 금지** (욕설은 원본 강도·의도에 맞게, 직역으로 강도가 달라지지 않게)
- 플롯상 중요한 대사가 배경 대사보다 우선
- 원본 톤을 유지하되 대상 시청자에게 자연스럽게
- 브랜드명은 현지 통용명 → 현지 대응명 → 일반명사 순

### 2.18 폰트 (I.7)

- Gulim (일반 proportional SansSerif 대체 표기), 흰색, 화면 가로에 16자가 들어가는 크기

### 2.19 참고 자료 (I.21)

- 국립국어원(korean.go.kr) 어문 규범, 띄어쓰기 지침, 외래어 표기법, 맞춤법 검사기

## 3. 넷플릭스 영어 번역 자막 (English USA TTSG **Section II**, 최신 2025-12-19)

비영어 → 미국 영어 번역 자막에 적용. 한국어 규정과 수치·표기가 **다르다.**

### 3.1 수치

| 항목 | 값 |
|---|---|
| 한 줄 글자 수 | 42자 |
| 읽기 속도 — 성인 | 20 CPS |
| 읽기 속도 — 아동 | 17 CPS |
| 줄 수 | 최대 2줄 |

### 3.2 주요 표기 (한국어와 다른 지점 위주)

- **이탤릭 사용함**: 내레이션, 속마음, 노래 가사(판권 시), 사전에 없는 외국어, 화면에 없는 화자의 전자 매체 음성, 작품 제목(에피소드·곡 제목은 따옴표), 부호로 못 살리는 강조
- **2인 화자: 공백 없는 하이픈**, 줄당 1명
- 연속성: `…`(U+2026), 2초 미만 연결은 부호 없음, 2초 이상·말끝 흐림은 말줄임표, 급작스러운 중단은 `--`
- 강제 자막(Forced Narrative): **전부 대문자**(프롤로그·에필로그 같은 긴 문단은 문장 형식), 대사와 같은 자막에 합치지 않음, 대사를 끊고 들어오면 앞뒤에 말줄임표
- 숫자: 0~10 문자, 11 이상 숫자. 문장 시작 숫자는 문자(3어절 이상·단위·날짜는 숫자 허용). 정확한 시각은 숫자 + 소문자 `a.m./p.m.`. `o'clock`은 숫자를 문자로. 나이는 항상 숫자
- 날짜: `March 6th` 형식(`the`, `of` 생략), 연대는 `1950s`, 세기는 `20th century`
- 인명: 승인 번역 없으면 번역 금지. **한국어 이름은 성-이름 순서 유지**, 남한식은 하이픈+두 번째 글자 소문자(`Kim Hee-sun`), 북한식은 하이픈 없음(`Kim Jong Un`), 중국어는 붙여 쓰고 첫 글자만 대문자(`Ning Shizheng`)
- 인용: 큰따옴표 기본, 인용 내 인용·곡 제목은 작은따옴표. 마침표·쉼표는 닫는 따옴표 **안쪽**, 콜론·세미콜론은 바깥
- 노래: 판권 + 플롯상 중요할 때만. 이탤릭, 각 줄 첫 글자 대문자, 줄 끝은 물음표·느낌표만. 앨범 제목 이탤릭, 곡 제목 따옴표
- 반복: 이름·단순 단어가 과하게 반복되면 **처음 2~3회만** 자막화
- 문장부호: 콜론·세미콜론 지양, 쉼표 남용 지양, 이중 공백 금지, en/em 대시 금지, `?!` 허용
- 다큐: 화자의 **직함만** 번역(이름·회사명 제외), 첫 등장 1회. 온스크린 등장 시 이탤릭 쓰지 않음
- 검열 금지, 욕설은 동등한 강도. `Black`, `Deaf`, `Indigenous` 대문자. 미국식 최빈 철자(`okay`)

## 4. 디즈니+ 번역 자막 — **미확보**

- 디즈니의 번역 자막 스타일 가이드(*Disney Digital Supply Chain Subtitle and CC Style Guide* 등)는 **파트너·벤더 전용 비공개 문서**다.
- 공식 웹에서 열람 가능한 것은 **시청자용 자막 표시 설정 안내**뿐이며 제작 규정이 아니다.
  - https://help.disneyplus.com/article/disneyplus-en-us-format-captions
- 웹에 도는 디즈니+ 수치(줄당 42자, 20 CPS, 최소 1초, 자막 간 2프레임, IMSC 1.1 등)는 **문서 공유 사이트 업로드본·번역업체 블로그 기반 2차 정보**다. 공식 확인 불가 → **룰로 채택하지 않는다.**
- 미확인 항목: 한국어 줄당 글자 수, 한국어 CPS, 최소·최대 표시 시간, 자막 간 간격, 이탤릭 정책, 강제 자막 표기, 인명 표기 규칙.
- **확보 경로**: 디즈니 로컬라이제이션 벤더 계약 시 제공되는 파트너 포털, 또는 DMED 파트너 담당자.

## 5. 쿠팡플레이 번역 자막 — **미확보**

- 쿠팡플레이는 자막 제작 스타일 가이드를 **공개하지 않는다.** (2026-08 기준 공개 문서 없음)
- **확보 경로**: 쿠팡플레이 콘텐츠 파트너팀 또는 납품 벤더에 직접 요청.

## 6. 교정기 룰 후보 — 번역 자막 전용

**넷플릭스 한국어 번역 자막 프로파일에만** 적용. SDH 프로파일과 분리할 것.

| # | 검사 | 근거 |
|---|---|---|
| T1 | 한 줄 > 16자 (라틴·공백·부호 0.5자 가중치) | I.2 |
| T2 | 읽기 속도 > 12 CPS (아동물 9 CPS) | I.15 |
| T3 | 3줄 이상 자막 | I.11 |
| T4 | 표시 시간 < 0.833초 또는 > 7초 | General Req. |
| T5 | **줄 끝 마침표·쉼표** | I.13 (한국어 전용 위반) |
| T6 | `...` → `…`(U+2026) 치환 | I.4 |
| T7 | 이탤릭 태그 `<i>` 존재 | I.10 (한국어 이탤릭 금지) |
| T8 | 이중 공백 | 공통 |
| T9 | 2인 화자 하이픈 뒤 공백 누락 | I.6 (한국어는 하이픈+공백) |
| T10 | 화면 텍스트에 작은따옴표 사용 / 인용에 큰따옴표 사용 (역전) | I.14 |
| T11 | 강제 자막과 대사가 한 자막에 혼재 | I.8 |
| T12 | 24시간제 표기, 원화 환산 흔적, 비미터법 단위 | I.12 |
| T13 | 영어 약어 안 마침표 (`D.V.D.`) | I.1 |
| T14 | 같은 자막 내 동일 어구 반복 번역 | I.16 |
| T15 | 가사 줄 끝 마침표·쉼표, 가사에 따옴표·이탤릭 | I.17 |
| T16 | 줄바꿈 위치 — 조사·의존명사 분리, 역피라미드 위반 | General Req. |
| T17 | 존댓말/반말 혼용 일관성 (에피소드 내 동일 관계) | I.19 |

> T5·T7·T9·T10은 **한국어 번역 자막에서만 위반**이다. 영어 자막에 그대로 걸면 오탐이 난다.

## 7. SDH vs 번역 자막 — 반드시 분리해야 하는 차이 (넷플릭스 한국어 기준)

| 항목 | 번역 자막 (Section I) | SDH (Section II) |
|---|---|---|
| 한 줄 글자 수 | 16자 | 16자 (동일) |
| 읽기 속도(성인) | **12 CPS** | **14 CPS** |
| 읽기 속도(아동) | **9 CPS** | **11 CPS** |
| 화자 표시 | 없음 | `[이름]` 대괄호 |
| 효과음 | 없음 | `[의성어/서술]` 대괄호 |
| 음악·가사 | 판권+플롯 중요 시만, ♪ 없음 | ♪ 로 감쌈, 곡 제목 식별자 사용 |
| 2인 화자 하이픈 | 하이픈 + 공백 | 출처가 다를 때만 하이픈 |
| 외국어 표시 | 작은따옴표 가능 | `[중국어]` / `[일어로 말한다]` |
| 화면 텍스트 | 큰따옴표 `" "` | (해당 규정 없음, 대사 전사 우선) |
| 원문 충실도 | 압축·함축 허용 | **의역 금지, 삭제·압축만** |
| 삐 처리 | 규정 없음(검열 금지) | 음절당 `*`, 전체는 `****` |
