# 외래어 표기법 — 예외 규정 모음

**원칙만 넣으면 오답 공장이 된다.** 외래어 표기법은 제1장 기본 원칙 아래 언어별 세칙이
붙고, 그 세칙에 다시 예외가 붙는다. 원칙만 기계에 넣으면 예외를 전부 위반으로 부른다.

출처: 작업자 실무 자료(번역가 교육 자료). 규정 원문은 국립국어원 어문 규범
「외래어 표기법」 제2장 표기 일람표·제3장 표기 세칙
(<https://korean.go.kr/kornorms/regltn/regltnView.do?regltn_code=0003>).

관련: `docs/BACKLOG.md` 31번(언어별 세칙 전면 도입, 우선순위 영어·독일어·프랑스어·
중국어·일본어).

---

## 1. 기본 원칙과 그 예외

| | 원칙 | 예외 |
|---|---|---|
| 제3항 | 받침에는 `ㄱ ㄴ ㄹ ㅁ ㅂ ㅅ ㅇ`만 | `커피숖`(x) `커피숍`(o) / `디스켙`(x) `디스켓`(o) |
| 제4항 | 파열음에 **된소리를 쓰지 않는다** | **동아시아 언어(중국·일본·태국·베트남)는 된소리 허용** — `똠양꿍`, `마오쩌둥` |
| 제5항 | 굳어진 외래어는 관용을 존중 | **관용 인정은 국어사전이나 국어원 용례에 등록된 어휘로만 제한** — `피애노`(x) `피아노`(o) |

**제4항 예외가 가장 위험하다.** 언어를 모르는 채 된소리 검사를 걸면 태국어·중국어
표기를 전부 오탐지로 잡는다(태국어 세칙: `t→ㄸ`, `k→ㄲ`, `p→ㅃ`, 유음 앞 파열음에는
`으`를 붙인다 — `Prathuang Phatko` 쁘라투앙 팟꼬).

**사전이 '규범 표기는 미확정'이라고 하면** 표준어로 인정하지 않는다는 뜻이다. 그때는
외래어 표기법을 따른다(예: 표기법상 `ㅟ` → `ㅣ`). `알콜` → `알코올`.

## 2. 영어 세칙의 예외

### 무성 파열음 [p] [t] [k]

| 자리 | 조건 | 표기 |
|---|---|---|
| 어말 | **단모음** + [p t k] | 받침 — `유닛`, `셔틀콕` |
| 어말 | 非단모음 + [p t k] | `으` 붙임 — `플루트`, `케이크`, `데스크` |
| 중간 | 단모음 + [p t k] + **`l r m n`이 아닌 자음** | 받침 — `냅킨`, `풋볼` |
| 중간 | 그 외 | `으` 붙임 — `디프레션`, `비트맵` |

### 유성 파열음 [b] [d] [g]

**무조건 `으`를 붙인다** — `로브스터`, `불도그`, `퍼브`.
**예외: `로브스터`는 2016년부터 `랍스터`도 허용.**

### [ʃ]

`쉬`를 쓰지 않는다. 모음 앞 `시`·`셰`, 자음 앞 `슈`, 단어 끝 `시`.
`shrimp` 쉬림프(x) **슈림프**(o).

### 그 밖의 영어 예외

| 예외 | 내용 | 예 |
|---|---|---|
| `-s` | 철자가 `s`로 끝나고 발음기호가 **/z/**면 **`스`** | `James /dʒeɪmz/` 제임스, `news` 뉴스, `busters` 버스터스 |
| (대조) | 발음기호가 **/ʣ/**면 `즈` | `Three Foods /θriː fuːʣ/` 스리 푸즈 |
| 예외 1 | **/əʊ/ · /oʊ/ → `오`** | `snow` 스노, `snowman` 스노맨, `snowboard` 스노보드, `Hello` 헬로, `rainbow` 레인보, `yellow` 옐로, `window` 윈도, `saw` 소 |
| 예외 2 | 철자가 **`a`로 끝나고** 발음기호가 **/ə/**면 **`아`** | `Sarah` 세라, `agenda` 어젠다, `Oprah` 오프라, `Jeremiah` 제러마이아, `Josiah` 조사이아 |
| 예외 2의 예외 | **`Mariah` 머라이어** — '머라이어 캐리'가 너무 유명해서 | |
| 예외 3 | 철자가 **`i` · `y`**이고 발음기호가 **/ə/**면 **`이`** | `sensitive /sensətɪv/` 센시티브, `recipe /resəpi/` 레시피 |
| `-ton` | 철자 `-ton`은 **모두 `턴`** | `Newton` 뉴턴, `Canton` 캔턴, `Egerton` 애저턴 |
| `-land` | **영어권 `랜드`, 독일어권 `란트`, 나머지 `란드`** | 스코틀랜드 / `Saarland` 자를란트 / `Lapland` 라플란드 |

## 3. 인명·지명의 예외

- **외국 지명은 현지음**을 따른다 — 모스크바(Moscow), 빈(Vienna), 바르샤바(Warsaw)
- **관용이 현지음과 많이 다르면 관용을 따른다** — `덴 하흐`(x) **`헤이그`**(o)
- **중국 인명·지명은 1911년 신해혁명이 기준** — 그 이전은 한자음, 이후는 중국어.
  `주윤발`(x) **`저우룬파`**(o)
- **일본 인명·지명은 언제나 일본어 발음** — `이등박문`(x) **`이토 히로부미`**(o)
- **중국·일본 지명은 관용과 현지음 둘 다 허용** — 동경/도쿄, 상해/상하이, 대만/타이완
- 바다는 `해`, 섬은 `섬`으로 통일 — 홍해·발트해·아라비아해 / 오아후섬·보라보라섬·이키섬
- **뜻이 겹쳐도 널리 쓰이면 허용** — 몽블랑산, 리오그란데강, 몬테로사산
- `and`가 든 지명은 **`and`를 빼고 띄어 쓴다** — `Jammu and Kashmir State` 잠무 카슈미르주,
  `King and Queen County` 킹 퀸 카운티
- **`Mac`/`Mc`은 관용이 우선** — `MacArthur` 매카서(x) **맥아더**(o)
- 이름 중간 별명은 앞으로 빼 작은따옴표. **단 유명하면 그대로 둬도 된다** —
  `마이클 '에어' 조던`

## 4. 상표명 — 외래어 표기법과 어긋난다

**외국 회사는 외래어 표기법을 따르지만, 한국에 지사가 있으면 등록상표를 따른다.**

    폴크스바겐(x) -> 폭스바겐(o)
    포르셰(x)     -> 포르쉐(o)
    도요타(x)     -> 토요타(o)

표기법대로 고치면 **등록상표를 틀리게 만든다.** 상표명은 표기법 규칙을 걸기 전에
등록상표부터 확인해야 하는 부류다(특허정보넷 KIPRIS).

## 5. 형용사형은 발음대로 옮기지 않는다

    Persian Architecture   페르시안 건축(x) -> 페르시아 건축(o)
    Asian Water Buffalo    아시안물소(x)   -> 아시아물소(o)
    Mexican Food           멕시칸 음식(x)  -> 멕시코 음식(o)

## 6. 같은 원어, 다른 표기 — 뜻이 갈린다

| 원어 | 표기 A | 표기 B |
|---|---|---|
| type | **타이프**(타자기) | **타입**(부류·형식) |
| cut | **커트**(잘라냄) | **컷**(영상 용어, =숏) |
| shot | **샷**(공을 침) | **숏**(영상 용어, =컷) |

**둘 다 맞는 표기이고 뜻이 다르다.** 한쪽으로 자동 통일하면 뜻을 바꾼다.

## 7. 고유명사 띄어쓰기 (국립국어원 내부 지침)

- **요리·음료 이름은 다 붙인다** — 양고기안심스테이크, 해산물볶음, 아이스모히토,
  딸기주스, 믹스커피
- **식재료는 요리가 아니므로 띄운다** — 바닐라 챤탈리 크림, 레몬 커드
- **수식 어구도 띄운다** — 인도풍 카레리소토, 새송이버섯을 곁들인 와규스테이크
- **외국 지명·도시명은 다 붙인다** — 뉴욕, 로스앤젤레스, 리우데자네이루
- **동식물 품종명은 다 붙인다** — 아프리카코끼리, 흰긴수염고래, 긴잎끈끈이주걱
- **하이픈이 든 이름·두 낱말 성·관사·전치사는 붙인다** — 장클로드 반담, 덩컨스미스,
  판데이크, 폰모어, 르몽드, 다빈치, 데라로차, 드니로
  (**같은 `de`가 스페인어는 `데`, 영어는 `드`** — 언어를 알아야 쓸 수 있다)
- 한국어·외래어 구분 없이 붙이는 어휘:
  자연 `해 섬 강 산 산맥 만 반도 호 곶 주 평야 고원` /
  행정구역 `성 관 도 현 부 주 시 가` / 문화 `어 인 족 왕 궁 사 성 요`

## 8. 검색 절차 — 국적 파악이 1단계다

```
단계 1  단어의 국적과 종류 파악
        (어느 나라 지명·인물인가 / 고유명사? 일반명사? /
         **영어 일반명사라면 영국 발음으로**)
단계 2  상표명·회사명 등 고유명사는 **국내에 등록된 정보** 확인
단계 3  상표 확인이 안 되거나 상표가 아니면 **국어원 용례 검색**

        [영/독/불]                       [그 외 언어]
단계 4  용례 없으면 발음기호 확보         용례 없으면 한글라이즈
단계 5  실패 시 용례 짜깁기 + 발음 듣기   일람표로 자음·모음 조합
                                          + 용례 짜깁기 + 발음 듣기
```

**단계 2가 단계 3보다 앞이다** — 등록상표가 국어원 용례보다 우선이라는 뜻이고, §4의
`폭스바겐`·`포르쉐`·`토요타`가 그래서 표기법과 어긋난 채로 정답이다.

**단계 1을 못 하면 나머지를 못 한다.** 지금 교정기는 낱말만 던지므로 이 절차를 밟을 수
없다. 국적·언어를 함께 넘기는 것이 백로그 31번의 첫 조각이다.

## 9. 용례를 찾을 때

**국명·언어명이 매우 중요하다.** 국립국어원 '용례 찾기'에서 `원어 표기` 조건과
`국명` 조건을 겹쳐 걸면 같은 철자가 언어마다 다르게 적히는 것을 가를 수 있다.
이름이 통째로 안 나오면 **검색을 짜깁기한다**(`Lauzon` 로종, `Marcoux` 마르쿠).

발음기호 확보: 일반명사는 Longman·Collins·Lexilogos, 고유명사는 Pronounce Names·
Wikipedia, 한글라이즈(hangulize.org), 상표명은 KIPRIS.

**일본어가 로마자로만 적혀 있으면 한글라이즈를 쓸 수 없다.** 일본어로 되돌린 뒤 찾는다
(`Koizumi Junichiro`가 준이치로인지 주니치로인지는 로마자만으로 알 수 없다).
