## 1. 넷플릭스 — 공통 기술 요건 (General Requirements, 최신 2022-10-07)

번역 자막·SDH **양쪽에 공통 적용**되는 층이다.

- **표시 시간**: 최소 5/6초(24fps 기준 20프레임), 최대 7초
- **줄 수**: 최대 2줄. 글자 수 제한 내에서는 1줄 선호
- **위치**: 화면 상단 또는 하단, 가운데 정렬 (일본어만 세로쓰기 허용). 화면 텍스트와 겹치면 위치 조정, 불가하면 가독성 우선
- **파일 포맷**: TTML1 (.xml/.ttml). 일본어는 IMSC 1.1
- **TTML 규격**: 값은 % 만(px 금지), `tts:textAlign`/`tts:displayAlign`로 위치 지정(정적 값), `tts:fontSize`는 100%
- **문자**: Netflix Glyph List에 포함된 문자만 사용
- **줄바꿈 원칙**
  - 문장부호 뒤에서 끊기, 접속사·전치사 앞에서 끊기
  - 분리 금지: 관사+명사, 형용사+명사, 이름+성, 주어 대명사+동사, 전치사구, 조동사·재귀대명사·부정어+동사
  - 선택지가 여럿이면 **아래 줄이 더 긴 역피라미드 형태**
- 시즌/에피소드 간 KNP(고유명사)·존댓말 테이블로 일관성 유지
- 통화 환산 금지 / 브랜드명은 현지 통용명 → 현지 대응명 → 일반명사 순

## 2. 넷플릭스 한국어 SDH (Korean TTSG **Section II**, 최신 2025-07-07)

원문 목차: II.1 Accuracy of content / II.2 Character Limitation / II.3 Reading Speed Limit / II.4 Line Treatment / II.5 Dual Speaker·Multiple Events / II.6 Foreign Dialogue / II.7 Songs and Music / II.8 Speaker IDs / II.9 Sound Effects / II.10 Special Instructions

### 2.1 수치 (II.2 / II.3 / II.4)

| 항목 | 값 |
|---|---|
| 한 줄 글자 수 | **16자** (라틴 문자·공백·문장부호는 0.5자로 계산) |
| 읽기 속도 — 성인 | **초당 14자** |
| 읽기 속도 — 아동 | **초당 11자** |
| 줄 수 | 최대 2줄, 글자 수 초과하지 않으면 1줄 |

> 번역 자막(12/9 CPS)보다 SDH가 더 빠르다. **이 차이가 SDH와 번역 자막을 분리해야 하는 대표적인 이유다.**

### 2.2 내용 정확성 (II.1)

- 원 대사를 최대한 포함. **단순화·순화 금지**
- 축약은 읽기 속도·싱크 문제가 있을 때만. 이때도 **의역이 아니라 삭제·압축** 우선
- 원본 사투리의 어휘·어순 그대로, 은어 유지
- 의도적 발음 오류는 플롯·캐릭터성에 관계될 때 재현. ㅐ/ㅔ처럼 변별되지 않는 발음 차이는 생략 가능
- TV·영화 클립 속 대사도 가능한 한 전부 전사, 플롯 중요도 우선
- 한국어 더빙 콘텐츠의 SDH는 더빙 대본을 참조해 읽기 속도·타이밍이 허용하는 만큼 일치시킴

### 2.3 화자 표시 (II.8)

- **대괄호 `[ ]`**
- 화자가 화면에서 시각적으로 식별되지 않을 때 사용. 이미 식별된 대사가 이어지면 추가하지 않음
- 정보 결합 시(출처/언어/말투) **언어 라벨은 맨 뒤**
- 미확인 인물: `[여자]`, `[남자]`. 같은 장면에서 중복되면 번호 부여, 장면이 바뀌면 초기화
- 일반 화자 표시는 엔딩 크레딧 참고, **스포일러 금지**
- 이름이 밝혀지면 이름 사용, 비중과 무관하게 일관 적용
- 전개에 따라 표시가 바뀔 수 있음: `[경찰]` → `[김 경위]` → `[진수]`

### 2.4 효과음 (II.9)

- **대괄호 `[ ]`**
- 단일 서술 / 의성어 / 의성어+음원 조합으로 표기. 가능하면 직관적인 의성어
- 시각적으로 식별되지 않는 소리를 설명. **소리를 설명하고 시각 요소·동작은 설명하지 않음**
- 소리를 내는 주체가 화면에 보이면 효과음에 화자 표시를 넣지 않음
- 플롯상 중요한 소리는 항상 표기, **의미 있는 정적(무음)도 표기**
- 부사를 활용해 소리·목소리·말 속도·크기를 구체적으로 묘사
- 어미는 다양하게 쓰되 **"들린다", "소리"는 지양** (포용적 표기)
- 실제 말더듬이 있는 화자가 아니면 `[말을 더듬으며]` 지양 → 전사에 반영하거나 `[주저하며]` 등 사용
- 대사를 끊는 효과음은 원본 오디오 순서대로 배치
- 일상어의 자연스러운 결합 사용, 난해한 표현 금지

### 2.5 2인 화자 / 복수 이벤트 (II.5)

- 출처가 다른 화자와 효과음은 **하이픈**으로 구분
- **효과음이 그 화자 본인에게서 나면 하이픈을 쓰지 않음**
- 출처가 다른 두 효과음도 하이픈으로 구분
- 각 줄은 완결된 문장. 앞뒤 자막으로 문장을 넘기지 않음

### 2.6 외국어 대사 (II.6)

- 번역이 제공되면 대사 앞에 `[언어]` (예: `[중국어]`)
- **원어(한국어)는 언어 표시 불필요**
- 알아들을 수 없는 외국어: `[일어로 말한다]` 형식
- **`[외국어로 말한다]` 절대 금지** — 언어를 반드시 조사할 것
- 식별 가능한 억양·방언이 플롯·캐릭터성에 중요하면 표기: `[영희/북한 억양]`
- 한국어 대사 속 외국어 단어는 표시 불필요, 대신 음역(철자·강세 확인)
- 가짜 언어/횡설수설: `[가짜 언어로 말한다]`

### 2.7 노래·음악 (II.7)

- 한국어 가사: 비디제틱은 플롯상 중요하고 대사를 방해하지 않으면 표기 / 디제틱은 플롯상 중요하면 표기 / 등장인물이 부르면 가능한 한 표기
- 한국 노래 속 로마자 외국어 가사는 번역 없이 그대로 포함
- 외국어 노래는 번역이 제공되거나 별도 지시가 있을 때 표기
- 곡 제목 표기: 비디제틱 `[가수의 '제목']`, 디제틱 `[가수의 '제목'가 흐른다]`
- 가사는 각 자막 앞뒤에 **음표 ♪**, 음표와 텍스트 사이 **공백 1칸**
- 듀엣은 노래하는 각 줄 앞뒤에 음표
- 배경으로 계속되지만 자막을 멈출 때 말줄임표
- 배경 음악 일반 표시 예: `[록 음악 - 라디오]`
- 장르·분위기는 객관적으로. 주관적 서술·스포일러성 서술 금지

### 2.8 특별 지시 (II.10)

- 화자 표시·효과음을 넣을 때도 **글자 수(가독성) 기준을 지킬 것**
- 특정 단어 삐 처리: **음절당 `*` 하나**
- 문장 전체 삐 처리: `****`

## 3. 넷플릭스 영어 SDH (English USA TTSG **Section I**, 최신 2025-12-19)

한국어 SDH와 **수치·표기 방식이 다르다.** 영어 SDH 납품 시에만 적용.

원문 목차: I.1 Accuracy of content / I.2 Character Limitation / I.3 Continuity / I.4 Dates and Decades / I.5 Documentary·Unscripted / I.6 Dual Speakers·Multiple Events / I.7 Font Information / I.8 Foreign Dialogue / I.9 Italics / I.10 Line Treatment / I.11 Numbers / I.12 Punctuation / I.13 Quotations / I.14 Reading Speed Limits / I.15 Songs / I.16 Speaker ID·Sound Effects / I.17 Special Instructions / I.18 Reference

### 3.1 수치

| 항목 | 값 |
|---|---|
| 한 줄 글자 수 | 42자 |
| 읽기 속도 — 성인 | 20 CPS |
| 읽기 속도 — 아동 | 17 CPS |
| 줄 수 | 최대 2줄 |
| 싱크 | 오디오에 맞추거나 2~3프레임 이내. 읽기 속도가 필요하면 오디오 종료 후 **최대 10~12프레임**까지 아웃 타임 연장 가능 |

### 3.2 표기

- 대사를 **의역하지 않는다**. 오디오에 최대한 가깝게 전사. 방언 특징도 그대로
- 화자 표시·효과음: 대괄호 `[ ]`, 고유명사 외 **소문자**, 미국 영어 어휘(`[running faucet]`, `tap` 아님)
- **화자 표시·효과음에는 절대 이탤릭을 쓰지 않는다** (대사가 이탤릭이어도)
- 미확인 인물: `[man]`, `[woman]`, `[male voice]`, `[female voice]`, 중복 시 번호(`[man 1]`)
- 화자 표시와 대사는 되도록 같은 줄
- `hmm`, `um`, `whoa` 등 준언어 요소는 플롯·분위기·캐릭터성에 관계되면 포함
- 실제 말더듬이 아니면 `[stutters]`, `[stammers]` 지양 → 전사에 반영하거나 `[hesitates]`
- 효과음은 시각적으로 자명하지 않으면서 플롯상 중요한 것만. **의미 있는 정적도 표기**
- 2인 화자: **공백 없는 하이픈**, 줄당 1명, `-[Name] Dialogue`
- 연속성: `…`(U+2026) 사용, 점 3개 금지
  - 2초 미만 간격으로 문장이 이어지면 말줄임표·대시 **없음**
  - 2초 이상 정적·말끝 흐림 → 말줄임표
  - 동작·소리·타인에 의한 급작스러운 중단 → **하이픈 두 개 `--`**
  - 자막 중간 시작 표시일 때만 공백 없이 앞에 말줄임표
- 이탤릭 사용처: 내레이션 / 속마음 / 노래 가사 / 사전에 없는 외국어 / **화면에 존재하지 않는 화자의 전자 매체 음성**(전화·TV·AI·내비) / 작품 제목(에피소드·곡 제목은 따옴표) / 부호로 못 살리는 강조
  - 화면 밖·문 뒤·프레임 밖일 뿐이면 이탤릭 아님
- 노래: 들리는 가사는 대사를 방해하지 않는 한 전부 자막화. 이탤릭 + 각 줄 앞뒤 ♪(공백 1칸), 각 줄 첫 글자 대문자, 줄 끝은 물음표·느낌표만, 곡 제목 식별자 `[Song Title playing]`
- 외국어: 번역되면 `[in Spanish]`, 이해 불가면 `[speaking Spanish]`, **`[speaking foreign language]` 금지**
- 문장부호: 콜론·세미콜론 지양, 쉼표 남용 지양, 이중 공백 금지, en/em 대시 금지, `?!` 허용
- 숫자: 0~10 문자, 11 이상 숫자, 나이는 항상 숫자, 정확한 시각은 숫자 + 소문자 `a.m./p.m.`
- 검열 금지. 원본이 삐 처리·묵음일 때만 `*`로, **들리는 음절만** 표기
- `Black`, `Deaf`, `Indigenous` 대문자. 미국식 최빈 철자(`okay`)

## 4. 디즈니+ SDH — **미확보**

- 디즈니의 SDH 스타일 가이드(예: *Disney Style Guide — English SDH*, *Disney Digital Supply Chain Subtitle and CC Style Guide*)는 **파트너·벤더에게만 배포되는 비공개 문서**다.
- 디즈니 공식 웹에서 접근 가능한 자막 문서는 **시청자용 자막 표시 설정 안내**뿐이고, 제작 규정이 아니다.
  - https://help.disneyplus.com/article/disneyplus-en-us-format-captions
- 웹에 떠도는 디즈니+ 수치(줄당 42자, 20 CPS, 최소 1초, 자막 간 2프레임, IMSC 1.1 등)는 **문서 공유 사이트 업로드본과 번역업체 블로그에서 나온 2차 정보**다. 공식 확인이 안 되므로 **이 프로젝트의 룰로 채택하지 않는다.**
- **확보 경로**: 디즈니 로컬라이제이션 벤더 계약 시 제공되는 파트너 포털, 또는 DMED 파트너 담당자에게 직접 요청.
- 한국어 SDH 관련 미확인 항목: 줄당 글자 수, 한국어 CPS, 화자 표시·효과음 표기 형식, 이탤릭 허용 여부, ♪ 사용 규칙.

## 5. 쿠팡플레이 배리어프리 자막 — **미확보**

- 쿠팡플레이는 오리지널 중심으로 화면해설·배리어프리 자막을 제공하지만, **공개된 자막 제작 스타일 가이드 문서가 존재하지 않는다.** (2026-08 기준)
- 공식 사이트·고객센터에도 제작 규정 문서가 없다. 시청자용 자막 설정 안내만 존재.
- **확보 경로**: 쿠팡플레이 콘텐츠 파트너팀 또는 배리어프리 제작 벤더에 직접 요청.

| S3 | 3줄 이상 자막 | II.4 |
| S4 | 표시 시간 < 0.833초 또는 > 7초 | General Req. |
| S5 | `[외국어로 말한다]` 사용 | II.6 (금지 표현) |
