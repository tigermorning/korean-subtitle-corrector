# 문제 정의서 — 문맥 의존 띄어쓰기의 근거 검색

> Main Quest 2 제출물. **실험을 돌리기 전에** 작성했고, 실행 후 기준을 바꾸지 않는다.
> 작성일 2026-08-12.

## 1. 도메인

영상 번역·자막 제작. 구체적으로는 이 저장소가 담당하는 **한국어 자막 교정**이다.

작업자는 영상을 받아 전사(STT) → 번역 → 한국어 교정 → 자막 규정 검수 순으로 일한다.
이 저장소(`korean-subtitle-corrector`)는 그중 **한국어 교정**을 맡고, 옆 저장소
(`subtitle-editor`)가 나머지를 맡으며 이 교정기를 라이브러리로 불러 쓴다.

교정기의 설계 원칙은 하나다 — **확률적 추측을 하지 않는다.** 국립국어원(표준국어대사전·
우리말샘·어문규범 API)이 정답을 하나로 확정해 주는 것만 자동으로 고치고, 확정되지
않으면 사람에게 넘긴다.

## 2. 현재의 문제

### 2.1 병목의 위치

한글 맞춤법 **제42항**은 여덟 낱말이 두 가지 문법 기능을 오간다고 규정한다.

> 들 / 뿐 / 대로 / 만큼 / 만 / 지 / 차(次) / 판

같은 글자인데 **앞말이 무엇이냐, 무슨 뜻이냐**에 따라 붙여 쓰기도 하고 띄어 쓰기도 한다.

    붙임: 너뿐이다 (조사)          띄움: 웃을 뿐이다 (의존명사)
    붙임: 잠만 자다 (보조사)        띄움: 십 년 만의 귀국 (의존명사)
    붙임: 인사차 들렀다 (접미사)     띄움: 입사 3년 차 (의존명사)
    붙임: 한판 잔치 (합성명사)       띄움: 한 판 더 하자 (수관형사+의존명사)

**사전 조회로는 이 판정이 안 된다.** `한판`도 표제어이고 `한 판`도 맞는 표기다. 어느
쪽인지는 "무엇을 세고 있는가"가 정하는데, 그건 문장 안에 있지 사전에 없다.

### 2.2 지금 어떻게 하고 있는가

`docs/GRAMMAR_PRECEDENTS_TABLE.md`에 기록된 현재 상태:

| 낱말 | 현재 처리 | 남은 문제 |
|---|---|---|
| 들·만·지 | 기존 규칙이 처리 | 없음 |
| 뿐 | 자동 교정 | 없음 (앞말 품사가 정답을 정함) |
| 차 | 자동 교정 + 플래그 | **`회사 차`(車)를 붙일 위험** — 가르는 신호가 kiwi 태그뿐 |
| 판 | **플래그만** | **판정을 포기하고 사람에게 넘긴다** |

그리고 이 프로젝트에는 국립국어원 온라인가나다 판례가 축적돼 있다
(`subtitle_corrector/gananda_precedents.py`). 그런데 **쓰는 방법이 정확 문자열 일치뿐**이다:

```python
# check_precedent(expression) — 표기가 정확히 일치할 때만 True/False
```

즉 판례에 없는 새 문장을 만나면 축적된 근거가 **하나도 동원되지 않는다.**

유사 판례를 임베딩으로 찾는 장치(`precedent_search.py`)도 이미 있다. 그러나 그 파일
서두가 이렇게 못박고 있다:

> 교정 판정에는 절대 쓰지 않는다. … 문장 임베딩 유사도는 규범 근거가 아니므로
> 자동 교정 결정에 이 점수를 쓰면 안 된다.

**지식은 쌓였는데 꺼내 쓰는 길이 정확 일치 하나뿐이다.** 이것이 병목이다.

### 2.3 그래서 무슨 일이 벌어지는가 (재현한 물증)

사전 조회가 살아 있는 환경에서 실제로 재현했다(2026-08-12).

```
'나 오늘 사진 하러 가'  ->  '나 오늘 사진하러 가'   ← 틀림
'공부 하러 간다'        ->  '공부하러 간다'         ← 맞음
```

두 낱말에 대해 사전이 주는 신호가 **완전히 같다**:

| 낱말 | `word_exists` | `is_contemporary_general_word` | 시스템 판정 | 정답 |
|---|---|---|---|---|
| 사진하다 | True | True | 붙임 | **띄움** |
| 공부하다 | True | True | 붙임 | 붙임 |

`docs/BACKLOG.md` 최우선 항목이 제안한 1차 조치(현대 일반어 게이트 확대)는 **이 문제를
못 푼다.** 게이트가 이미 둘 다 통과시키고 있기 때문이다. 이 사실은 이번에 처음 확인했다.

## 3. 개선 가설

> 국립국어원 뜻풀이·용례·판례를 **문맥 기반으로 검색**해서 현재 문장에 맞는 근거를
> 꺼내 오면, 사전 조회(불리언) 단독보다 문맥 의존 띄어쓰기를 더 정확하게 판정할 수 있다.

AI를 넣는 자리는 **판정기가 아니라 검색기**다. 정답을 모델이 만들지 않는다 — 모델은
"이 문장에 해당하는 근거가 어느 것인가"만 고르고, 판정은 그 근거가 한다. 이렇게 하면
프로젝트의 최우선 원칙(확률적 추측 금지)을 깨지 않고도 축적된 지식을 동원할 수 있다.

**반증 가능하게 세운다.** 검색이 사전 단독보다 낫지 않으면 가설은 기각이고, 그때는
백로그 2안(오프라인 빈도표)이 답이라는 결정이 남는다.

## 4. 대상 사용자

1. **영상 번역 작업자** (주 사용자) — 자막 한 편에 이런 판정이 수십 번 나온다. 지금은
   플래그를 보고 매번 직접 판단한다.
2. **이 저장소의 유지보수자**(나) — 규칙을 하나 고치면 반대쪽이 무너지는 문제를 겪어
   왔다. 근거를 검색으로 대면 규칙 증식을 줄일 수 있는지 확인하려 한다.
3. `subtitle-editor` 사용자 — 편집기가 이 교정기를 그대로 불러 쓰므로 개선이 자동 전파된다.

## 5. 성공 기준 (실행 전 확정)

평가셋에 대해 arm별 정확도를 재고, **아래 넷을 모두 만족해야 "통합할 가치가 있다"**로 본다.

| # | 기준 | 값 |
|---|---|---|
| S1 | 근거 검색(B2)의 정확도가 현재 시스템(B0)보다 높다 | > B0 |
| S2 | 근거 검색의 **오답률** | ≤ 5% |
| S3 | 판정마다 국립국어원 출처를 제시할 수 있다 | ≥ 90% |
| S4 | 같은 입력 → 같은 출력 (B3 제외) | 100% |

**S2가 핵심이다.** 이 도구는 틀린 교정을 내보내지 않는 것이 정확도보다 중요하다.
정확도가 올라가도 오답률이 5%를 넘으면 자동 적용할 수 없고, 그러면 "플래그만 하는"
현재 동작과 다를 바가 없다.

하나라도 실패하면 **"만들지 않는다"**로 결론내고 백로그 2안을 권고한다.

## 6. 비교 대상 (arm)

| arm | 방법 | 성격 |
|---|---|---|
| **B0** | 현재 시스템 전체 (규칙 + 사전 + kiwi) | **기준선** |
| **B1** | 축적 판례 정확 일치만 (`check_precedent`) | 현재의 검색 방식 |
| **B2a** | 근거 검색 — 낱말 겹침 (비신경) | 저장소에 이미 있는 방식(§73 `건초` 판정) |
| **B2b** | 근거 검색 — 문장 임베딩 | **AI 모델을 쓰는 arm** |
| **B3** | 로컬 LLM 직접 판정 | 확률적 대조군 |

B2a를 반드시 함께 돌린다. **임베딩이 답이라고 가정하지 않기 위해서다** — B2a가
B2b와 비슷하면 임베딩은 만들지 않는다는 결정이 나온다.

## 7. 제약 확인 (성능보다 먼저)

| 항목 | 결정 |
|---|---|
| 프라이버시 | 전부 로컬 + 국립국어원 공식 API. 외부 LLM에 원고를 보내지 않는다 |
| 라이선스 | 임베딩 `paraphrase-multilingual-MiniLM-L12-v2` (Apache 2.0). LLM은 `exaone3.5`(상업 제약 있음) → **B3는 대조군으로만 쓰고 결론 근거로 삼지 않는다** |
| 실행 환경 | 로컬 CPU. GPU 불필요 |
| 메모리 | 임베딩 모델 약 500MB — `KNOWN_LIMITATIONS.md`에 기록된 Render 무료 티어 512MB 한계 때문에 **서버 경로에는 절대 넣지 않는다.** 감수자 로컬 실행 전용 |
| 비용 | 0 |

## 8. 예상 실패 모드

- 평가셋이 작아 통계가 안 선다 → 40건 미만이면 결론을 "잠정"으로 명시한다
- 뜻풀이가 짧고 정형적이라 임베딩 유사도가 뭉갠다
- 검색이 맞는 근거를 찾아도 **적용 규칙이 따로 필요**해서, 결국 규칙을 또 짜게 된다
- 국립국어원 API 지연 (기존 `lru_cache`로 완화)
